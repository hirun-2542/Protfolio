## Run Locally

โปรเจกต์นี้เป็น HTML และ CSS ล้วน ไม่ต้องติดตั้ง dependencies

```bash
git clone https://github.com/hirun-2542/Protfolio.git
cd Protfolio
python3 -m http.server 8000
```

จากนั้นเปิด <http://localhost:8000>

## Deployment

เว็บไซต์ deploy อัตโนมัติไปยัง GitHub Pages เมื่อมีการ push เข้า `main`
ผ่าน workflow ที่ `.github/workflows/pages.yml`
